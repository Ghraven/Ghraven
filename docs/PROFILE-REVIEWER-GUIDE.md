# Profile Reviewer Guide

This page is a short path for people reviewing Rolly Calma's GitHub profile for work, collaboration, or open-source context.

## Best first checks

1. Open the portfolio at <https://rollycalma.com/>.
2. Review the proof gallery at <https://ghravenlabs.github.io/>.
3. Inspect one runnable Python project:
   - <https://github.com/GhravenLabs/Website-QA-Auditor>
   - <https://github.com/GhravenLabs/Mini-RAG>
   - <https://github.com/GhravenLabs/python-utils-toolkit>
4. Check recent public pull requests for maintainer communication style, test notes, and follow-through.

## What to look for

- Small, focused changes with a clear before/after explanation.
- Practical Python and automation work instead of placeholder demos.
- Tests, smoke checks, or manual verification notes close to the code.
- Documentation that explains how to run or inspect the project.

## Current positioning

Rolly is looking for junior Python, AI automation, developer tooling, or open-source support roles. The profile is intentionally proof-first: live demos, source code, case studies, and contribution history should be easy to find from the first screen.
